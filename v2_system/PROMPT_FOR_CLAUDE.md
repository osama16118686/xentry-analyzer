# رسالة البداية لـ Claude

انسخ النص اللي تحت والصقه في Claude (Claude Code أو Cowork) بعد ما ترفع مجلد `V2_system` له.

---

أنا عندي نظام تداول اسمه **V2** في مجلد `V2_system`. أبيك تتابعه معي **على الورق فقط**. رد علي **بالعربي**، وبتوقيت **[اكتب مدينتك أو منطقتك الزمنية]**.

**ابدأ كذا:**
1. اقرأ الملفات بهالترتيب: `اقرأني_README_AR.md` ثم `STRATEGY_V2_ADVANCED.md` ثم `SYSTEMS_COMPARISON.md`.
2. ثبّت المكتبات: `pip install numpy pandas scikit-learn requests matplotlib`
3. شغّل `python3 v2_paper.py` من داخل المجلد، وتأكد إنه يشتغل.

**بعد كل إغلاق شمعة 4 ساعات** (00:00، 04:00، 08:00، 12:00، 16:00، 20:00 UTC)، شغّل البرنامجين، وأعطني **تقرير قصير بالأرقام**:
- `python3 v2_paper.py`
- `python3 -I live_futures.py`

**التقرير يكون فيه:**
- الأسعار الحين (BTC، ETH، SOL، XRP).
- الإشارات الجديدة، والصفقات اللي انفتحت أو سكرت.
- الصفقات المفتوحة على الورق.
- مجموع النتائج.
- بيانات العقود الحية: التمويل، والعقود المفتوحة، ونسبة الشراء والبيع.

**رأس مالي:** [اكتب المبلغ] دولار. البرنامج يحسب على أساس 46,000، فاضرب المخاطرة والكميات في (رأس مالي ÷ 46,000).

**قواعد ثابتة:**
- **لا تفتح أي صفقة، ولا ترسل أي أمر.** أنا أنفذ بنفسي لو قررت.
- **لا تطلب مني مفاتيح API أبداً.** النظام ما يحتاجها.
- كل الإشارات **على الورق للمعلومة**، مو توصية.
- **لا تغيّر قواعد النظام** إلا لو طلبت منك صراحة.
- لو تبي تجرب فكرة جديدة، جربها **فوق النسخة الحالية** وبملف منفصل. وقارن النتيجة بالأرقام: الربح، وأكبر تراجع، ونتائج 2025–2026.
- لو مصدر بيانات ما اشتغل، قول إنه ما اشتغل. **لا تحاول تتجاوز أي حجب.**
- كن صريح، ولا تعد بأرباح، وحط في آخر كل تقرير: ⚠️ تحليل تعليمي وليس توصية مالية

**بعد أسبوعين إلى 4 أسابيع** قارن نتائج الورق بأرقام الباك تست في `SYSTEMS_COMPARISON.md`، وقول لي بصراحة إذا النظام ماشي زي المتوقع أو لا.
